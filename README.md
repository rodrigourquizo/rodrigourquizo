## 🚀 Featured projects

### 🦅 [HAWKEYE: AI surveillance with drones](https://github.com/rodrigourquizo/HAWKEYE)
Real-time person detection from a drone with YOLOv8, protected-zone filtering to cut false alerts, instant Telegram notifications and a Flask monitoring dashboard. Featured in a [national news report](https://andina.pe/agencia/noticia-estudiantes-ingenieria-crean-dron-vigilancia-usa-ia-para-preservar-huaca-994243.aspx).

`Python` `YOLOv8` `PyTorch` `OpenCV` `Flask` `Telegram API`

### 🧠 [Credit risk classification with LLMs on AWS](https://github.com/rodrigourquizo/Fraud_Detection_AI)
Pipeline that uses Llama 3 on Amazon Bedrock to label applicant risk profiles, then trains and deploys an XGBoost classifier on Amazon SageMaker for good/bad credit risk inference.

`Python` `Amazon Bedrock` `SageMaker` `XGBoost` `LLMs` `MLOps`

### 🕳️ [Real-time 3D reconstruction of sewer pipes](https://github.com/rodrigourquizo/3D_reconstruction)
Combines 2D LiDAR point clouds with video from a robot's trajectory and builds a mesh with Poisson surface reconstruction for infrastructure inspection. **Published by Springer:** [read the paper](https://link.springer.com/chapter/10.1007/978-3-032-18982-0_16).

`Python` `LiDAR` `Computer Vision` `Point Clouds` `Poisson Reconstruction`
